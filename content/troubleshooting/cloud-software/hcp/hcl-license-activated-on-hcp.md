title: HCL License Activated on HCP
order: 20
---

1. Save the customer's existing license on HCP, and then deactivate it locally.
2. Uninstall HCP and install HCL.
3. Hikvision unbinds the HCL license in the back-end system. The customer activates the license on the local HCL server and then deactivates it again. Hikvision confirms that the final license status in the system is deactivated.
4. The commercial team submits the license cancellation request.
