---
id: troubleshooting-hcp-license-file-corrupted
title: License File Corrupted
order: 10
---

1. Hikvision submits a license unbinding request.
2. Stop the HCP SYS service.
3. Delete the fnood file in the root directory of drive C: after backing it up.
4. Restart the HCP SYS service.
5. Activate the license again.
