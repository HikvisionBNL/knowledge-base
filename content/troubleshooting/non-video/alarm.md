Normally, provide the following information:

1. Device model, firmware version, and serial number
2. Specific symptom, reproduction frequency, and environment topology
3. Configuration screenshots and a video showing the issue
4. Troubleshooting steps already performed, such as restarting, resetting, upgrading, or changing the network
5. HPP after-sales code valid for 72 hours, and remote log collection enabled for 72 hours

For specific zone logic, configuration methods, firmware upgrade questions, and similar topics, please consult separately.
